# Product demo video

An 83-second narrated walkthrough of FinSight-AI, made with [HyperFrames](https://hyperframes.heygen.com):
the film is an HTML page with a GSAP timeline, rendered to MP4.

The rendered film is at [`docs/media/finsight-demo.mp4`](../docs/media/finsight-demo.mp4).

## Change it and render again

```bash
cd video
python3 narrate.py        # only after changing a spoken line or the voice
python3 build.py          # writes index.html; each scene is timed to its narration
npm run check             # lint, layout, motion and contrast checks
npm run render            # writes renders/<name>.mp4 (kept out of git)
```

- **A scene**: edit its line in `build.py`: the screenshot, headline and one sentence of
  text. Its length follows the narration.
- **What is said**: edit the line in `narrate.py`, then run `python3 narrate.py <scene>`.
- **The voice**: change `VOICE_ID` in `narrate.py` to any voice from the ElevenLabs voice
  library and run `python3 narrate.py`. The narration uses the project's
  `ELEVENLABS_API_KEY` from `.env.local`.
- **A picture**: replace the file in `assets/`. The screenshots are of the app running on
  the synthetic dataset.

The music bed is generated by `build.py` with ffmpeg from four sine tones, so there is no
sample to license. Replace `assets/music.mp3` after building to use a different track.
