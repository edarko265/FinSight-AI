### Added

- Next.js 16 App Router scaffold with strict TypeScript, Tailwind CSS, ESLint, Prettier
  and Vitest.
- Integer-cent money parsing and formatting.
- Field-level encryption (AES-256-GCM, per-customer keys, blind indexes).
- Security headers and a `/api/health` build-info endpoint.
- CI: pull request validation, branch-promotion policy, CodeQL, dependency review and
  audit, gated deployment, release tagging, Dependabot.
- Project documentation: scope, implementation plan, conventions, branching, security and
  database recommendation.
